# 智能合约分析方法(深度:函数+权限+事件)

## ABI 获取(按可用性排序)

1. milon MCP 可用:`contract_read`(读合约状态)、`idl_methods`/`idl_apps`(方法清单)
2. 区块浏览器 API 按地址拉已验证合约 ABI
3. 用户直接给 ABI JSON 文件
4. 都没有 → 用户提供源码,手动提取函数签名

## 三类提取

### 1. 函数 → 功能点
每个 external/public 函数 = 1 个功能点:
- view/pure 函数 → 读正确性用例(返回值 vs 链上状态)
- 状态函数 → 写路径用例(状态变化 + 事件断言 + 失败零副作用)
- payable 函数 → 加金额边界(0/超额/恰好)用例

### 2. 权限修饰符 → 权限用例
| 修饰符模式 | 用例 |
|---|---|
| onlyOwner / onlyRole(x) | 无权调用 revert + 有权成功 + **授权后立即生效/撤销后立即失效** |
| 角色转移类 | 转移后原地址失去(即时性)、最后一名管理员保护类函数 |
| 白名单/暂停 | 未列入拒绝、pause 后全拒、unpause 恢复 |

### 3. 事件 → 断言点
- 每个状态函数通常配 1 个事件:事件字段 = 用例断言清单
- 断言时机:交易回执的事件,而非仅交易成功
- 重复触发同业务(同幂等键)→ 事件不得重复发射

## 合约特有维度(叠加到 9 维)

- **精度**:solidity 整数运算,金额换算(10^decimals)边界、除法截断方向
- **重入**:写函数是否有跨合约调用(分析用,不强制测;需要时标悬置)
- **Gas 异常**:参数极端值导致 out of gas → 用例标 P2
- **链上确定性**:同一交易哈希重放 → 链上只生效一次

## 输出物

| 产物 | 形式 |
|---|---|
| 函数清单 | 签名 | 可见性 | 修饰符 | 关联事件 | 对应接口(如有) |
| 权限矩阵 | 角色 × 函数 允许/拒绝 表 |
| 断言点清单 | 事件名 → 字段断言 |
| 悬置项 | 源码看不到内部逻辑时的假设 |
