# 用例格式规范

## 一、xlsx 手工用例(11 列固定)

| 列 | 列名 | 填写规范 |
|---|---|---|
| A | 用例编号 | `TC-<模块缩写>-<序号>`:TC-SR-001。模块缩写从既有表沿用,新模块取拼音/英文前2-3字母 |
| B | 一级模块 | 产品名(如 代币经济学) |
| C | 二级模块 | 功能域(如 搜索),与追溯表功能点一致 |
| D | 用例标题 | **公式:`模块-操作-条件-预期`**(搜索-完整合约地址精确定位代币);禁止"验证xx功能"式模糊标题 |
| E | 优先级 | P0/P1/P2,按下方风险规则 |
| F | 前置条件 | 编号列出;含测试数据怎么来(账户/代币/证书谁持有) |
| G | 操作步骤 | 编号动作,**每步一个可执行操作**(输入X/点击Y/断网),不写分析不写预期 |
| H | 预期结果 | 编号对应步骤;**可判定陈述**(显示什么文案/跳哪个页/数据变多少);数值标"按配置动态推导";**无依据坚决不猜:留空标【待确认】**,交付时单独列出待补清单,禁止私自按"最合理实现"填写 |
| I | 实际结果 | **下拉单选 pass/fail/skip/block(四色),只能选不能手输**;生成时留空 |
| J | 测试结论 | 留空(执行时填) |
| K | 备注 | 依据与悬置说明:原型Frame ID / PRD条款号 / 接口字段 / "实现为直达也算通过(与开发确认)" |

### 优先级风险定级规则

| 级 | 判定(满足其一) |
|---|---|
| **P0** | 资金相关(扣款/退款/赔付/守恒);权限越权;主流程不可用(无法注册/下单/搜索);数据丢失 |
| **P1** | 输入校验/边界;状态机非法跳变;异常提示与零副作用;并发幂等;配置联动 |
| **P2** | 体验/文案/布局;防抖性能;统计类;锦上添花项 |

### 完整示例行(照此粒度写)

| TC-SR-008 | 代币经济学 | 搜索 | 搜索-完整合约地址精确定位代币 | P0 | 1. 已知某代币完整合约地址 | 1. 复制完整合约地址粘贴到搜索框并回车 | 1. 精确定位该代币(结果唯一或 Tokens 分组第一条)
2. 点击直达 Token 详情 | (空) | (空) | 原型未画直达跳转,若实现为直接跳详情也算通过(与开发确认) |

要点:标题用公式;步骤=纯动作;预期=可判定;数值动态推导;备注=依据+悬置说明。

## 二、实际结果列下拉(强制)

`scripts/xlsx_writer.py` 自动配置,手写等效代码:
- DataValidation list: `"pass,fail,skip,block"`,errorStyle=stop,**手输其他值被 Excel 拦截**
- 条件格式四色:pass=绿底(C6EFCE/006100) fail=红底(FFC7CE/9C0006)
  skip=灰底(E7E6E6/595959) block=黄底(FFEB9C/9C6500)
- 应用范围:I2:I5000(幂等,已有同配置不重复加)

## 三、pytest 自动化用例模板

```python
# -*- coding: utf-8 -*-
"""<模块>:<功能点>。<依据:PRD条款/接口字段>。"""
import pytest
from tests.lib.client import TfClient, error_code  # 按项目实际客户端替换
from tests.lib.helpers import dec

pytestmark = pytest.mark.<marker>   # smoke/orders/... 按项目 marker 体系

def test_<模块>_<功能点>_<场景>(user):   # 命名:模块_功能_场景
    """<标题公式同xlsx>。失败必须零副作用。"""
    # 1) 配置动态读(铁律1)
    rules = read_rules(user)
    # 2) 执行动作
    st, body = user.post("/path", {...})
    # 3) 断言三件套:状态/业务语义/零副作用
    assert st == 201, body
    assert dec(body["fee"]) == expected_from(rules)   # 期望从配置推导
    assert balance(user) == bal_before                # 被拒场景零扣款
```

### pytest 用例硬性要求
- 期望值运行时读配置/接口,零硬编码(文档值仅 WARN 基线)
- 每个失败路径用例带零副作用断言(余额不变/无记录产生)
- 并发用例用 threading,断言"绝不透支/只生效一次"
- 环境不可构造时 pytest.skip 带具体原因,不静默通过
- 涉及配置写入:备份→写→finally还原→断言恢复(见 test-dimensions 维度7)
- 文件头 docstring 写 PRD/接口依据;每条用例 docstring 写标题公式

## 四、追溯 sheet 格式

| 功能点 | 覆盖用例 | 用例数 |
|---|---|---|
| 搜索 | TC-SR-001, TC-SR-002... | 22 |
| 充值 | ⚠️ 未覆盖 | 0 |

- 未覆盖行红色加粗;`scripts/xlsx_writer.py --features` 自动生成
- 功能点与 C 列二级模块用词必须一致(追溯按此匹配)
